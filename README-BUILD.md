# Petal Control — GitHub APK Releases

This is the **Petal Control V3 Android Studio project**, as compiled in the previous build environment, with an updated GitHub Actions workflow that builds a **debug/test APK** and publishes it to GitHub Releases when a version tag is pushed. The ZIP contains source, not an APK.

## For Claude Code / Antigravity

1. Extract this ZIP into its session, including the hidden `.github` folder.
2. Verify every file. The GitHub repository `Houssam-2021/PetalControlCenter` was empty when checked; re-check before writing.
3. Push the extracted files to `main` using the authenticated GitHub connector if the `GH_TOKEN` environment variable is invalid. Do not request tokens in the chat or force-push.
4. On each push to `main`, Actions builds and uploads a temporary artifact but does NOT create a release.
5. After reviewing the build and available tests, create and push a tag `v0.2.0-test` if explicitly authorized to publish. GitHub Actions will build a second time and publish `PetalControl-v0.2.0-test.apk` as a **pre-release** on the Releases page.
6. On repository Settings → Actions → General → Workflow permissions, allow 'Read and write permissions' if GitHub denies the release job. `contents: write` in workflow is needed but not always sufficient.
7. Verify the Actions result and uploaded asset, and report any tests that have *not* been performed.

## Local build

Requires Android SDK Platform 35, Build Tools 35.0.0, Java 17, and Gradle wrapper 8.11.1 (downloads on first run).

`./gradlew :app:assembleDebug`

Output: `app/build/outputs/apk/debug/app-debug.apk`

## Important caveats

- Successful compilation has previously been confirmed (2026-11-01) with JDK 17 / Gradle 8.11.1 / Android SDK 35. This packaged copy has not been independently installed on an emulator or physical device.
- The debug APK is signed using an Android debug key generated by each build environment. An updated build may not install as an in-place update over another debug build due to different keys; back up any app state first.
- Petal Control cannot replace Samsung's normal notification shade, and some protected toggles open system settings rather than operating directly. Do not claim all functionality is implemented or visually pixel-perfect.
- No app-store/release signing keys are included.
